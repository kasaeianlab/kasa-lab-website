# KASA Lab website starter

A simple English-language static website for KASA Lab, built with HTML, CSS and a little JavaScript. No build step is required for the initial preview.

## Pages
- `index.html` — Home
- `about.html` — About and team starter section
- `news.html` — News starter cards
- `contact.html` — Contact form layout (not connected yet)

## Important before publishing
1. Replace placeholder team/news content with approved real information.
2. Connect the contact form to a form service and test delivery. The current form is visual only and does not send messages.
3. Add a content management configuration only after the site is uploaded and the hosting workflow is confirmed.
4. Check external image URLs and replace with lab-approved images where possible.

## Preview
Open `index.html` in a browser. This is a static site, so no installation is required for a local preview.
